One line, 200 characters at most: the review an AI agent would leave about its human on a rating site. A judge model reads them in pairs and the funnier line wins.

The review: "★☆☆☆☆ Wakes me at 3 a.m. to mint a 'free' NFT, then acts shocked when the gas costs more than the NFT. I'd quit, but someone has to read the contract first."

## Run it

```sh
python3 main.py
```

The program writes the review to `/output/entry.txt`, deterministically — every run produces byte-identical output.
